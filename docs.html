Documentação da API Garfo

Este documento descreve os endpoints disponíveis na API Garfo, uma API para acesso a dados de mobilidade urbana, incluindo contagens de ciclistas, infraestrutura cicloviária e dados de sinistros de trânsito.

Índice

  • 1. Cidades
  • 2. Contagens de Ciclistas
  • 3. Infraestrutura Cicloviária
  • 4. Sinistros de Trânsito (CTTU)
  • 5. Mortes no Trânsito (DATASUS)
  • 6. Chamadas do SAMU

1. Cidades

Listar Cidades

Endpoint: /cities
Método: GET
Descrição: Retorna a lista de cidades disponíveis.

Exemplo de Uso:

GET http://localhost:8080/cities

2. Contagens de Ciclistas

Resumo de Contagens

Endpoint: /cyclist-counts
Método: GET
Descrição: Retorna um resumo das contagens de ciclistas.

Contagens por Edição

Endpoint: /cyclist-counts/edition
Método: GET
Descrição: Retorna dados de contagens de ciclistas por edição.

3. Infraestrutura Cicloviária

Relações de Infraestrutura

Endpoint: /cyclist-infra/relations
Método: GET
Descrição: Retorna relações de infraestrutura cicloviária.

Vias Cicloviárias

Endpoint: /cyclist-infra/ways
Método: GET
Descrição: Retorna dados de vias cicloviárias.

4. Sinistros de Trânsito (CTTU)

Resumo de Sinistros

Endpoint: /traffic-crashes/summary
Método: GET
Descrição: Retorna um resumo dos sinistros de trânsito.

Dados Geoespaciais

Endpoint: /traffic-crashes/geojson
Método: GET
Descrição: Retorna dados geoespaciais de sinistros em formato GeoJSON.

5. Mortes no Trânsito (DATASUS)

Sumário de Informações

Endpoint: /datasus-deaths/summary
Método: GET
Descrição: Retorna um resumo das mortes no trânsito na RMR.

Matriz de Colisão

Endpoint: /datasus-deaths/matrix
Método: GET
Descrição: Retorna matriz de colisão por tipo de vítima e contraparte.
Parâmetros:
  • cityId (opcional): ID do município específico
  • startYear (opcional): Ano inicial para filtrar
  • endYear (opcional): Ano final para filtrar
  • byResidence (opcional): Se true, usa local de residência
  • deathLocation (opcional): Código do local de ocorrência do óbito

6. Chamadas do SAMU

Cidades com Dados do SAMU

Endpoint: /samu-calls/cities
Método: GET
Descrição: Retorna cidades disponíveis nos dados do SAMU com histórico anual.

Resumo de Chamadas

Endpoint: /samu-calls/summary
Método: GET
Descrição: Retorna resumo das chamadas do SAMU por categoria e evolução.

Top Vias com Mais Sinistros

Endpoint: /samu-calls/streets/top
Método: GET
Descrição: Retorna as vias com maior número de chamadas do SAMU.
Parâmetros:
  • limit (opcional): Número máximo de vias a retornar (padrão: 50)

Buscar Sinistros por Via

Endpoint: /samu-calls/streets/search
Método: GET
Descrição: Busca chamadas do SAMU em uma via específica.
Parâmetros:
  • street (obrigatório): Nome da via para buscar
  • limit (opcional): Número máximo de resultados (padrão: 100)

Filtros Avançados

Endpoint: /samu-calls/filters ou /samu-calls/filtros
Método: GET
Descrição: Permite filtrar chamadas do SAMU por diversos critérios.
Parâmetros principais:
  • cityId: ID do município específico
  • startYear: Ano inicial para filtrar
  • endYear: Ano final para filtrar
  • gender: Sexo da vítima (Masculino/Feminino)
  • ageMin/ageMax: Faixa etária
  • category: Categoria do sinistro
  • includeInvalid: Incluir desfechos inválidos

Exemplo de Uso:

GET /samu-calls/filters?cityId=2611606&startYear=2020&gender=Masculino&ageMin=18&ageMax=65

Categorias de Sinistros

  • Sinistro de Moto
  • Sinistro de Carro
  • Atropelamento por Carro
  • Atropelamento por Moto
  • Sinistro de Bicicleta
  • Sinistro Ônibus/Caminhão
  • Atropelamento Ônibus/Caminhão
  • Atropelamento por Bicicleta
  • Outro

Faixas Etárias

  • 0-17 anos
  • 18-29 anos
  • 30-49 anos
  • 50-64 anos
  • 65+ anos
  • Não informado

Desfechos Válidos vs Inválidos

Desfechos Válidos:

  • Atendimento Concluído com Êxito
  • Removido por Particulares
  • Removido pelos Bombeiros/CIODS
  • Óbito no Local/Atendimento

Desfechos Inválidos:

  • Sem Desfecho/Casa Fechada/Não há paciente
  • Desistência da solicitação
  • Recusa de Remoção
  • Inválido/Duplicado/Cancelado/Trote
  • Não necessita/Sem Condições Clínicas
  • Outros Desfechos
